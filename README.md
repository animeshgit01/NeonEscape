# A 2D top-down arcade survival game built in C# (.NET, WinForms).

Survive waves of enemies in a neon-lit arena. Dodge, collect energy orbs, 
and stay alive as long as possible.

# Features
- Top-down movement and combat
- Enemy AI that chases the player
- Energy orb collection for power-ups/scoring
- Simple, fast-paced arcade gameplay

# Tech Stack
- C# / .NET
- Windows Forms (WinForms)

# How to Run
1. Clone the repo:
   git clone https://github.com/animeshgit01/NeonEscape.git
2. Open `NeonEscape.sln` in Visual Studio.
3. Build and run (F5).

# Controls
- Arrow keys / WASD — Move

# Project Structure
- `GameForm.cs` — Main game window and loop
- `Enemy.cs` — Enemy behavior and logic
- `EnergyOrb.cs` — Collectible orb logic
- `Program.cs` — Entry point
